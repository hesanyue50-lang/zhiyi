# 知忆

本地优先的陪伴型 AI 聊天应用。Android 原生（Kotlin + Compose），数据全部留在手机上。

她不是"一个会说人话的助手"，而是一个**有阴影的人**——会装作不在意、会怕被丢下、记得的事会随时间变淡。

---

## 它和别的陪伴应用差在哪

### 1. 人格有「向往」和「阴影」

大部分产品的人设是「性格：安静、克制、观察力强」。这只够做一个平面人。

这里有六个文档：身份 / 使命 / 关系 / 底线 / **向往** / **阴影**。

后两个是让她**自相矛盾**的地方：

- 向往：想被人需要，但不想承认
- 阴影：怕被丢下，所以先装作没事

两条一起，才会产生「被忽略时先缩一下再装作没事」「听到某句话突然认真」「给建议时带着自己的私心」这种具体行为。只写形容词永远写不出来。

### 2. 记忆会变淡，不是二进制

每条事实有两个独立维度：

| | 含义 |
|---|---|
| 重要度 | 当初它有多重要（静态） |
| **清晰度** | 现在还记不记得清（随时间衰减，重要度越高衰减越慢） |

保底 0.15——**记不清 ≠ 忘了**。人能说出「好像有这么回事，具体记不清了」，这个半模糊状态恰恰最像人。

### 3. 人格改动有账，能回滚

发布 = 追加一个新版本，历史永不删除。
回滚 = 把旧版本重新发布一次（产生新版本，历史一条不少）。

所以「改坏了」永远有退路。

### 4. 声音是克隆的，语气是算出来的

- 音色：上传 15 秒人声，克隆
- 语气：人格 + 九维心境 + 八类场景 → 让模型算出「这句该怎么念」
- 语速音高：累 → 慢 0.16，绷着 → 快 0.12，高兴 → 快 0.10（pitch 幅度不超 ±3%，超了就不像她了）

### 5. 旁白是旁白，台词是台词

```
（她抬眼看你）「嗯。」*然后低头继续翻书*
```

渲染成：灰色斜体 `她抬眼看你` → 气泡 `嗯。` → 灰色斜体 `然后低头继续翻书`。

五种引号都认（`「」` `『』` `“”` `""` `‘’`），括号一个都不露出来。

### 6. 是面对面，不是网聊

提示词里写死了：你们在同一个空间、没有屏幕隔着、没有"发送"和"收到"。

于是她不会说「消息」「收到」「在吗」，不会用「哈哈」代替笑，可以沉默、可以打断、可以和你同时开口。

## 使用

### 需要自备

| 项 | 用途 | 说明 |
|---|---|---|
| OpenAI 兼容 API | 聊天 / 记忆抽取 / 嵌入 | DeepSeek、硅基流动、各类网关都行 |
| MiMo TTS Key | 声音克隆 | 小米 MiMo，voiceclone 模型（目前限时免费） |

两个 Key 都**只存在本机**（SharedPreferences / SQLite），不联网、不上传、不进代码。

### 装

从 [Releases](../../releases) 下载 APK 直接安装。

- 最低 Android 8.0（API 26）
- 权限：麦克风（语音输入）、无障碍（桌宠看屏幕，可选）、通知（主动搭话，可选）

---

## 编译

```bash
export ANDROID_HOME=/path/to/android-sdk
./gradlew :app:assembleRelease
```

产物：`app/build/outputs/apk/release/app-release.apk`

用 debug keystore 签名（首次发布者自用）。要正式分发请换成自己的 release keystore，否则换机器升级会签名冲突。

## 结构

```
app/src/main/java/app/zhiyi/
├── core/          ChatCore —— 单一消息流，串行保证不乱序
├── memory/        提示词拼装（Assembler）、记忆抽取、心境、语气场景
├── llm/           零依赖 OpenAI 兼容客户端（HttpURLConnection + org.json）
├── voice/         MiMo TTS、声音样本、语气导演
├── pet/           桌宠：立绘、看屏幕搭话、气泡
├── proactive/     主动搭话（阈值由心境算，不是固定数）
├── data/          SQLite（7 版）、模型定义、存储清理
└── ui/            Compose 界面

app/src/main/assets/voice/   内置声音样本
```

## 已知限制

- **整条无引号、无冒号、无括号的纯文字只能当台词**——它也可能是她说的一句话，猜错更糟
- **用 debug keystore 签名**，换设备安装可能 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`
- **内置声音样本版权归米哈游**，配音演员有声音权。仅自用，请勿商用或二次分发
- **不支持 assistant 前缀续写**（prefill）——实测 DeepSeek 官方、beta 端点、各类兼容网关都不支持，只有 Anthropic 原生接口和 DeepSeek 自家 App 内部有
